# Комплект методической разработки по АЗН-В

Практикум для методиста: учащиеся декодируют **сырые** кадры ADS-B/АЗН-В формата dump1090 (`*HEX;`) и отдельно смотрят, что отдаёт OpenSky REST (уже обработанные векторы).

## С чего начать

1. Открыть [МЕТОДИЧЕСКАЯ_РАЗРАБОТКА.md](МЕТОДИЧЕСКАЯ_РАЗРАБОТКА.md), печатный [МЕТОДИЧЕСКАЯ_РАЗРАБОТКА.html](МЕТОДИЧЕСКАЯ_РАЗРАБОТКА.html) или Word [МЕТОДИЧЕСКАЯ_РАЗРАБОТКА.docx](МЕТОДИЧЕСКАЯ_РАЗРАБОТКА.docx).
2. Распечатать [учащиеся/рабочий_лист.md](учащиеся/рабочий_лист.md) (есть и `.docx`).
3. Выдать файлы из [эфир/занятие/](эфир/занятие/) — там нет ответов.
4. Ключи держать в [преподаватель/ключи.md](преподаватель/ключи.md).
5. После задания 9 показать [карта.html](карта.html) — куда «прилетает» AFL1410.

Контрольный кадр методиста:

```text
*8D7C1BE8581B66E9BD8CEEDC1C9F;
```

Это DF17, ICAO24 `7C1BE8`, высота 4350 фут, нечётный CPR. Разбор — в ключах, задание 1.

## Инструменты

Браузер, без установки:

- открыть [decoder.html](decoder.html)
- открыть [карта.html](карта.html) (офлайн, без тайлов карт)
- открыть [маршрут.html](маршрут.html) — загрузка своих координат на карте (GitHub Pages: папка `docs/`)

Python:

```text
pip install -r requirements.txt
python учащиеся/простой_декодер.py эфир/занятие/07_борт_VIR27X.txt
python tools/decode_aznv.py эфир/занятие/01_контрольный.txt
python tools/decode_aznv.py эфир/занятие/01_контрольный.txt --lat -31.94 --lon 115.97
python tools/decode_aznv.py эфир/россия/эфир_одновременный_unix.txt
python tools/decode_aznv.py эфир/россия/эфир_одновременный_unix.txt --tracks-json эфир/россия/треки_из_кадров.json --tracks-step 2
python tools/fetch_opensky.py --lamin 55 --lomin 36.5 --lamax 56.5 --lomax 38.5
python tools/listen_dump1090.py --seconds 30
python tools/aznv_encode.py
python tools/aznv_encode_rf3.py
python tools/build_map.py
```

На занятии скрипт лучше давать после ручного разбора высоты и позывного.

## Откуда эфир

| Папка | Что внутри |
|---|---|
| `эфир/занятие/` | Кадры к заданиям 1–7 |
| `эфир/сырые/` | Выборка OpenSky / учебная подборка AVR |
| `эфир/обработанные/` | JSON REST OpenSky (уже декодировано) |
| `эфир/россия/` | Учебный синтетический эфир: 5 бортов, SVO→LED, Unix-метки |
| `эфир/живой/` | Сюда пишет `listen_dump1090.py`, если есть SDR |

Как самостоятельно достать данные: [учащиеся/как_получить_данные.md](учащиеся/как_получить_данные.md).
